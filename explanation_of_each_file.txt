what each file does


bootloader source files (Bootloader/Core/Src/)

Bootloader.c
  main bootloader logic. runs on reset, checks if button is held or update was requested,
  enters update mode if so. receives encrypted firmware over UART, decrypts each chunk,
  verifies CRC + signature + version at the end, then installs.

flash.c
  low level flash operations. unlock/lock the flash, erase a sector, write bytes.
  bare metal register writes to FLASH->CR and FLASH->SR.

protocol.c
  packet parser. reads bytes one at a time into a state machine (sync, type, seq, len, data, crc).
  also sends ACK and NACK packets back to the PC.

usart.c
  sets up USART2 at 115200 baud on PA2 (TX) and PA3 (RX).
  interrupt-driven receive, bytes go into the ring buffer.

ring_buffer.c
  circular buffer used by the UART interrupt. interrupt writes in, main loop reads out.
  prevents dropped bytes when main is busy.

crc.c
  uses the STM32 hardware CRC peripheral on AHB1. feeds 32-bit words, reads back CRC32.
  same polynomial as the Python side.

jump.c
  jumps to the application. checks stack pointer and reset vector first.
  disables interrupts, moves the vector table, sets the stack pointer, calls the app reset handler.

aes_gcm.c
  AES-128-GCM encrypt and decrypt built on top of tiny-AES-c.
  GCM adds an authentication tag per chunk so tampered data is detected before it touches flash.

sha256.c
  SHA-256 hash. used to derive the session key (SHA256 of UID + nonce) and to hash the firmware
  before ECDSA signature verification.

aes.c
  AES-128 block cipher from tiny-AES-c (Kokke, public domain).

uECC.c
  ECDSA P-256 from micro-ecc (Kenneth MacKay, BSD 2-clause).
  verifies the firmware signature at the end of the update.


header files (Bootloader/Core/Inc/)

Bootloader.h     flash addresses and sector numbers
flash.h          flash function prototypes
protocol.h       packet types, packet struct, parser return values
usart.h          USART2 init and send prototypes
ring_buffer.h    ring buffer struct and function prototypes
crc.h            CRC init and calculate prototypes
jump.h           jump function prototype
aes_gcm.h        encrypt and decrypt prototypes
aes.h            tiny-AES-c API
sha256.h         SHA256 struct and update/final prototypes
uECC.h           micro-ecc verify prototype
pubkey.h         hardcoded P-256 public key as a byte array, generated by gen_pubkey.py


python files (SecureBootloader_F4/SecureBootloader_F4/)

send_firm.py
  main PC tool. signs the firmware, opens the serial port, handshakes, derives the session key,
  sends encrypted chunks, sends UPDATE_DONE with CRC + version + signature.

  python send_firm.py app.bin COM11 --version=2

  needs private.pem in the same folder.

gen_pubkey.py
  takes public.pem and writes pubkey.h for the bootloader to compile in.
  run once after generating a key pair, then rebuild the bootloader.

  python gen_pubkey.py public.pem Bootloader/Core/Inc/pubkey.h

make_bad.py
  generates a random wrong key and writes it to wrong_private.pem.
  used by test_wrongkey.py to sign firmware with a key the bootloader will reject.

test_wrongkey.py
  signs firmware with the wrong key and sends it. board should return VERIFY FAILED.

test_rollback.py
  sends firmware with version 0. board should return ROLLBACK BLOCKED.


other files

Application.bin
  pre-built application firmware. send with send_firm.py.
